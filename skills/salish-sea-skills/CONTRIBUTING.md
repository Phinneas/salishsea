# Contributing

Thanks for interest in improving Salish Sea Skills. Here's how to help.

## What we accept

- **Documentation improvements.** Clarifications, examples, rewordings.
- **New examples.** Sample outputs from real-world runs (anonymize if needed).
- **Bug reports.** Errors, typos, broken references.
- **Methodology questions.** If you ran a skill and something didn't work, we want to know.

## What we don't accept

- **Don't claim these as your own.** These frameworks are MIT licensed; you can use them commercially, but you must attribute them.
- **Don't sell access to these.** They're free. Keep them free.
- **Don't misrepresent endorsement.** If you use a framework, don't say "Phinneas endorses this approach" unless he actually said that.

## How to contribute

### Report an issue
Open a GitHub issue and describe:
1. Which skill?
2. What happened?
3. What did you expect to happen?
4. (Optional) How can we reproduce it?

### Suggest a change
For small docs changes, open a PR directly. For big changes (new skills, major rewrites), open an issue first so we can discuss.

### Add an example
Found a real-world use case? Create an `examples/` folder in the skill directory with:
- A brief description of the scenario
- Input (what you fed the skill)
- Output (what the skill produced)
- Result (what changed?)

Anonymize sensitive data.

## Process

1. Fork the repo
2. Create a branch (`fix/better-wording` or `example/nonprofit-grant-workflow`)
3. Make your change
4. Test it (if applicable)
5. Open a PR with a description of what you changed and why

## Questions?

File an issue. We'll respond.
