# Design Brief Enforcer: Anti-Slop Specs

**What:** Build/refine UI + copy with spec-enforced design briefs — no templated defaults.  
**When:** You're building a page/feature and need to enforce strategic direction into execution.  
**Output:** Design spec + copy + component specs — ready for dev or designer.

## Use Cases

- You have a design brief (**design-what-if**) and need to translate it to actual pages
- Your designer keeps defaulting to safe/generic — you need a checklist to prevent it
- You're building landing pages, homepages, or critical flows and can't let them look like every other site
- You need to hand off to a dev or designer with zero ambiguity

## The Skill

This skill runs a spec-enforced build:

1. **Define the brief:** Strategic direction (from **design-what-if**), aesthetic vocabulary, reference sites
2. **Decompose pages:** Break into components, sections, interactions
3. **Enforce specs:** Each component has hard values (spacing, typography, color, interaction timing)
4. **Critique pass:** Review against the brief — does it deliver on the feeling/concept?
5. **Output:** Figma spec or detailed markdown that prevents default thinking

**Key principle:** Every decision is intentional. No "looks good" — every pixel earns its place.

## Prerequisites

- A design brief (from **design-what-if**, or you write one)
- Reference sites that embody the aesthetic
- Willingness to be specific (not vague)

## Getting Started

```
Use the design-brief-enforcer methodology to spec out [page/feature]
```

Claude will:
1. Break down the page into components
2. Assign hard specs (spacing, font sizes, timing)
3. Review against your brief (does it feel right?)
4. Produce a spec sheet or Figma brief

## Time Investment

- **Per page:** 2–3 hours
- **Revisions:** 30 minutes per iteration

## Output

- **Figma spec:** A file designers/devs can hand off to build
- **Or:** Detailed markdown with component breakdown, spacing, typography, timing, interactions

## Workflow

Usually follows strategic direction (**design-what-if**) and feeds into dev handoff.

```
design-what-if → design-brief-enforcer → [build/design]
```

## Next Steps

- Hand to designer or dev
- Monitor execution — enforce the spec during QA
- Iterate if execution drifts from the brief
