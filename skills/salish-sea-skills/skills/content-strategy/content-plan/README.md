# Content Plan: Reasoning Lift Framework

**What:** 5-stage buyer-journey audit + AI/reasoning-mode content strategy.  
**When:** You have traffic/awareness but need to build intent and conversion.  
**Output:** Content plan organized by buyer stage + publishing calendar.

## Use Cases

- You rank for awareness keywords but don't convert
- You need to map your content to the actual buyer journey
- You're building content for high-reasoning tasks (research, comparison, decision)
- You're planning content for different LLM reasoning modes

## The Skill

This skill maps your content (or gaps) across 5 buyer stages:

1. **Awareness:** "Is this a problem I have?"
2. **Consideration:** "What are my options?"
3. **Evaluation:** "Which option fits?"
4. **Decision:** "How do I buy this?"
5. **Advocacy:** "How do I succeed after buying?"

Plus: Content optimized for minimal-reasoning mode (facts, lists) vs. high-reasoning mode (deep analysis, comparisons) for AI models.

**Key insight:** Most sites stack all content in "awareness" and "decision." Consideration and evaluation are where you win.

## Prerequisites

- Previous content audit (or this will start fresh)
- SE Ranking + DataforSEO (optional, to identify keywords for each stage)
- Clear understanding of your buyer journey (you can define it or let Claude infer it)

## Getting Started

```
Use the content-plan reasoning-lift methodology for [your domain]
```

Claude will:
1. Interview you on your buyer journey (or infer it from your site)
2. Audit existing content against the 5 stages
3. Identify content gaps
4. Prioritize what to build (aligned with traffic potential + conversion impact)
5. Output a calendar + content briefs

## Time Investment

- **First run:** 6–8 hours (includes journey definition, gap analysis)
- **Iterations:** 2–3 hours (refreshing the calendar, adding new stages)

## Workflow

Usually follows **seranking-dataforseo** and feeds into **design-what-if**.

```
seranking-dataforseo → content-plan → design-what-if → design-brief-enforcer
```

## Output

A Notion database (if connected) or markdown document with:
- 5-stage buyer journey mapped to keywords
- Content gap analysis (what's missing?)
- Priority ranking (fix first, what matters)
- 4-week publishing calendar
