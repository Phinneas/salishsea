# Design What If: Strategic Brief Framework

**What:** Design reframe pipeline — find the hidden truth, commit to one core idea, design for emotion.  
**When:** You have a project direction but it feels generic. You need a *concept*.  
**Output:** One-sentence design brief + emotional target + core hero feature.

## Use Cases

- Your site/app redesign feels safe but uninspired — reset the concept
- You need to pitch a vision to the team/client before building
- You're pivoting positioning — need a visual/strategic direction to match
- You're stuck between three mediocre directions — this forces a choice

## The Skill

This skill runs a full design reframe (Satori Graphics framework):

1. **Hidden Truth:** What's the one thing nobody's saying about your problem/market?
2. **What If:** If we committed fully to that truth, what would we do?
3. **Feel:** How should this make the user *feel*? (Not look like — feel like)
4. **Combine:** Merge feeling + truth into a core visual/positioning idea
5. **Brief:** Write the one-sentence design brief

Output: A strategic direction that's opinionated and buildable, not a compromise.

## Prerequisites

- Clear project scope (redesign? New product? Repositioning?)
- Willingness to be opinionated (this kills the "safe" option on purpose)
- Team buy-in that strategy comes first, then design

## Getting Started

```
Use the design-what-if methodology to find the core concept for [your project]
```

Claude will:
1. Interview you on the hidden truth of your market/brand
2. Push you to commit to one idea (not three)
3. Define the emotional target
4. Write the strategic brief
5. Suggest how this looks/feels in practice

## Time Investment

- **First run:** 2–3 hours (strategy session)
- **Revisions:** 30 minutes per iteration

## Next Steps

- **Design-brief-enforcer:** Use the brief to spec individual pages/features
- **Pass to design team:** Use the brief + emotional target to guide visual direction

## Workflow

Usually follows content planning (**content-plan**) and precedes detailed specs (**design-brief-enforcer**).

```
content-plan → design-what-if → design-brief-enforcer
```
