## How we version

- **PATCH** (1.0.1): Typo fixes, clarifications, new examples
- **MINOR** (1.1.0): New skills, significant examples, updated references
- **MAJOR** (2.0.0): Methodology changes or significant restructuring

Each SKILL.md includes its own publication version at the top (e.g., "Published in v1.0").
