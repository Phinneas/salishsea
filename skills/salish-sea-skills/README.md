# Salish Sea Skills Library

Production-tested frameworks for marketing, grant writing, sustainability, and operations.

**31 free frameworks** across 6 categories. All tested on real properties. All free to use in Claude.

---

## Quick Start

### How to use these in Claude

**Option 1: Import directly**
Search for any skill by name in Claude's skill marketplace (e.g., "seo-technical-audit"). Import and run.

**Option 2: Copy the SKILL.md**
Find the skill in this repo, copy the `SKILL.md` file, and use it as a custom instruction or skill in Claude.

**Option 3: Ask Claude directly**
Say "Use the [skill-name] methodology to..." and Claude will apply the framework.

## About These Frameworks

All 31 frameworks are:

- **Production-tested.** Every framework has been run on real properties (BinLocators, SoakColorado, Salish Sea Consulting, GaiaVerity, etc.)
- **Formalized.** Each SKILL.md is the production specification—not a prompt template, but the actual methodology.
- **Free to use.** No login wall, no gatekeeping. MIT licensed.
- **Designed for teams.** These work standalone or chained together.

Most skills take 4–8 hours to run initially, then 2–3 hours per iteration.
