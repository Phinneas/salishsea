## Prerequisite A: Fix sitemap trailing-slash inconsistency

Static pages in `src/app/sitemap.ts` lack trailing slashes while all canonical URLs and dynamic routes use them. This creates a sitemap/canonical mismatch Google will flag.

**File:** `src/app/sitemap.ts` (lines 11-18)

**Change:** Append `/` to each static route URL:
```
${BASE}/services  →  ${BASE}/services/
${BASE}/work      →  ${BASE}/work/
${BASE}/skills    →  ${BASE}/skills/
${BASE}/templates →  ${BASE}/templates/
${BASE}/about     →  ${BASE}/about/
${BASE}/blog      →  ${BASE}/blog/
${BASE}/contact   →  ${BASE}/contact/
```

Root (`BASE`) stays as-is — trailing slash on root is nonstandard.

## Prerequisite B: No broken-post fix needed

The plan said `conscious-copywriting` and `10-sustainability-trends-2025` are 404ing due to empty `publishedAt`. After auditing the code:

- `getAllPostSlugs()` reads ALL `.mdx` files regardless of `publishedAt`
- `getPost()` returns the post regardless of `publishedAt` (falls back to epoch date)
- `generateStaticParams()` uses `getAllPostSlugs()` — so pages ARE generated
- Both posts are already in the live sitemap (confirmed from earlier session)

**No fix needed.** The 404 claim doesn't match the code. Posts render with a "January 1, 1970" date. If that date is a UX concern, we can add real dates, but that's cosmetic, not a 404 fix.
