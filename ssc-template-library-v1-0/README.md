# Salish Sea Consulting Template Library — Version 1.0

This package contains the six SSC templates approved for the first release. The assets are designed to be edited in Microsoft Word or Excel and opened in compatible office suites. Green-tinted cells and bracketed text are intended for user input; blue-gray cells generally contain guidance or formulas.

| Product | Files | Best use |
|---|---|---|
| Letter of Support | `ssc-letter-of-support-template-v1-0.docx` | Prepare a credible, partner-specific grant support letter. |
| Standard Operating Procedure | `ssc-standard-operating-procedure-template-v1-0.docx` | Document repeatable work, ownership, evidence, exceptions, and review. |
| Logic Model | `ssc-logic-model-template-v1-0.docx`; `ssc-logic-model-workbook-v1-0.xlsx` | Design and explain a program’s causal chain, outcomes, indicators, and assumptions. |
| Grant Budget | `ssc-grant-budget-template-v1-0.xlsx` | Build and reconcile a funder-ready line-item budget and narrative. |
| Competitor Analysis | `ssc-competitor-analysis-template-v1-0.xlsx` | Collect evidence, compare competitors consistently, and identify testable positioning opportunities. |
| SEO Audit | `ssc-seo-audit-report-template-v1-0.docx`; `ssc-seo-audit-issue-tracker-v1-0.xlsx` | Verify, prioritize, communicate, and validate technical SEO findings. |

## Recommended workflow

Start with the **Instructions** sheet or the **How to use this template** section. Replace bracketed placeholders, remove example rows once their purpose is clear, and preserve an untouched master copy. Spreadsheet formulas recalculate automatically when opened in a current office application. Wide evidence sheets are configured to print across more than one page so that exported text remains readable.

## Quality and limits

The templates were checked for package integrity, document pagination, workbook formulas, validation rules, tables, charts, headers, footers, and brand consistency. They remain general planning and communication resources, not legal, tax, accounting, certification, financial, cybersecurity, accessibility-conformance, or professional engineering advice. Requirements vary by funder, jurisdiction, platform, organization, and project. Review final materials with the appropriate qualified professional and governing guidance.

The SEO assets reference current Google Search Central documentation within the files. Search visibility and performance outcomes are not guaranteed.
