## Recommended use

Start with each document’s “How to use” page or workbook Instructions sheet. Replace bracketed prompts, validate example formulas before deleting example rows, and retain an untouched master. Follow the current source, platform, policy, contract, accounting, funder, insurer, regulator, emergency, legal, and professional requirements governing the real work.

The Statement of Work is a contract-adjacent working draft for qualified attorney review and is not a complete agreement. The Business Continuity Plan is an operational continuity template, not a substitute for emergency response, life-safety, cybersecurity incident-response, technical disaster-recovery, or regulatory plans. The Risk Assessment workbook supports structured judgment but does not establish framework, audit, insurance, or regulatory conformance.
